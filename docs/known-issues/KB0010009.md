# KB0010009: Printer on 3rd floor not printing

**Category:** Hardware  
**Assignment group:** Desktop Support  
**Resolved example tickets:** INC0010061, INC0010105, INC0010149

## Symptoms
Jobs sit in the queue and nothing prints on the 3rd floor printer.

## Cause
A stuck job in the print server queue, or the printer has dropped off the network after a power cycle.

## Resolution
1. Check the printer's display for paper jams or errors.
2. On the print server, open the queue for the printer and delete the stuck first job.
3. Ping the printer's IP. If there is no reply, power cycle it and check the network cable.
4. Send a test page.
