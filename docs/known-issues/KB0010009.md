# KB0010009: PC hardware faults (disk, USB, audio, memory)

**Category:** Hardware  
**Assignment group:** Hardware  

## Tickets

- INC0000601: The USB port on my PC stopped working (Closed)
- INC0009002: My computer is not detecting the headphone device (Closed)
- INC0000028: My disk is still having issues. Can't delete a file (Closed)
- INC0000026: Seem to have an issue with my hard drive... (Closed)
- INC0000025: Need to add more memory to laptop (In Progress)

## Symptoms
A part of the user's computer fails: a USB port, headphones not detected, disk errors or files that can't be deleted, or not enough memory.

## Cause
Failing hardware, a missing or bad driver, or a machine below the current specification.

## Resolution
1. Restart the computer and check Device Manager for errors on the device.
2. Reinstall or update the driver (audio, USB, chipset) from the manufacturer or Software Center.
3. For disk problems, run `chkdsk /f` and check the drive's health (SMART). Back up the user's data first if it's failing.
4. For memory, check the model's maximum and order the upgrade, or swap the laptop if it is below spec.
5. If a part has failed, log a hardware repair or replacement with the asset tag.

## Notes
A failing disk is urgent. Back up first, then repair.
