# KB0010005: SAP report export to Excel not working

**Category:** Application  
**Assignment group:** SAP Support  
**Resolved example tickets:** INC0010059, INC0010064, INC0010066, INC0010079, INC0010080

## Symptoms
Export to spreadsheet in SAP GUI does nothing or opens an empty file.

## Cause
SAP GUI security settings block the Excel macro, or the export format default is set to an old XLS template.

## Resolution
1. In SAP GUI, Options > Security > Security Settings, set the rule for the export path to Allow.
2. In the report, choose List > Export > Spreadsheet, then pick 'Excel (in Office 2007 XLSX format)' and tick 'Always use selected format'.
3. Update SAP GUI to the approved version if it is older than 7.70.
