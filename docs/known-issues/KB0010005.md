# KB0010005: Shared drive and file share access

**Category:** Storage  
**Assignment group:** Network  

## Tickets

- INC0009009: Unable to access the shared folder. (New)
- INC0007002: Need access to the common drive. (New)
- INC0000059: Unable to access team file share (New)
- INC0000002: Network file shares access issue (On Hold)
- INC0000049: Network storage unavailable (In Progress)
- INC0000014: Missing my home directory (Closed)

## Symptoms
User can't open a shared folder, team share or home directory, gets access denied, or the network drive is missing or unavailable.

## Cause
Either the user isn't in the security group for that share, the drive mapping is missing, or the file server or network storage is down.

## Resolution
1. Ask for the exact path (for example `\\server\share`) and the error message.
2. If several users can't reach the same share, check the file server or NAS in monitoring and treat it as an outage.
3. If one user gets access denied, check the share's security group. Add them only with the data owner's approval.
4. If the drive or home directory is missing, remap it or run `gpupdate /force` and sign out and back in.
5. Confirm the user can open and save a file.

## Notes
A request for new access (like INC0007002) should go through the access request catalog item, not an incident.
