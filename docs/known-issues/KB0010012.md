# KB0010012: Website checkout returns error 500

**Category:** Web  
**Assignment group:** E-commerce Platform  
**Resolved example tickets:** INC0010062, INC0010068, INC0010136, INC0010138

## Symptoms
Customers see error 500 at checkout or when paying.

## Cause
Usually the payment provider's API is timing out, or a recent deployment broke the checkout service.

## Resolution
1. Raise a P1; this affects revenue.
2. Check the payment provider's status page and the checkout service error logs.
3. If a deployment went out in the last 2 hours, roll it back.
4. Link customer and internal reports to the P1 as duplicates.

## Notes
E-commerce on-call owns this.
