# KB0010012: Business app access and slowness (Sales, SFA, payroll portal)

**Category:** Application  
**Assignment group:** Software  

## Tickets

- INC0000046: Can't access SFA software (New)
- INC0000048: Having problems with Sales Tools performance (On Hold)
- INC0000007: Need access to sales DB for the West (On Hold)
- INC0001990: Unable to access the personal details section in payroll portal (On Hold)

## Symptoms
One user can't get into a business app or one part of it, or the app is slow for them.

## Cause
Missing role or license, a page the user's role doesn't allow, or performance problems on the app or its database.

## Resolution
1. Ask for the exact app, page and error message.
2. Check the user's roles and license in the app. Missing access goes to the access request process with manager approval.
3. If it's slow, check whether others see it too. If yes, check the app and database servers. If no, check the user's network and browser.
4. Confirm the user can reach the page they need.

## Notes
If the whole app is down for everyone, use KB0010004.
