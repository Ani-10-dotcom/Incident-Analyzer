# KB0010001: VPN disconnects for remote users

**Category:** Network  
**Assignment group:** Network Ops  
**Resolved example tickets:** INC0010047, INC0010048, INC0010083, INC0010102, INC0010116

## Symptoms
VPN tunnel drops every few minutes, mostly on home Wi-Fi. User has to reconnect repeatedly.

## Cause
The VPN client's idle timeout and MTU are too aggressive for consumer routers, and older client versions (below 5.2) don't recover from Wi-Fi power saving.

## Resolution
1. Confirm the client version in the VPN app's About screen. Upgrade to the current approved version from Software Center if it is below 5.2.
2. Set the adapter MTU to 1400: run `netsh interface ipv4 set subinterface "VPN" mtu=1400 store=persistent` as admin.
3. Turn off Wi-Fi power saving: Device Manager > Network adapter > Power Management > untick 'Allow the computer to turn off this device'.
4. Ask the user to reconnect and stay connected for 15 minutes to confirm.

## Notes
If drops continue on a wired connection, escalate to Network Ops with the client log (%ProgramData%\VPN\logs).
