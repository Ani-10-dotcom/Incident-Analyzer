# KB0010001: Email server outage

**Category:** Email  
**Assignment group:** Hardware  

## Tickets

- INC0009005: Email server is down. (New)
- INC0000032: EMAIL Server Down Again (Closed)
- INC0000050: Can't access Exchange server - is it down? (In Progress)
- INC0000039: Trouble getting to Oregon mail server (New)

## Symptoms
Several users at once cannot send or receive mail, or one site cannot reach its mail server. Users ask whether the email or Exchange server is down.

## Cause
The Exchange or regional mail server is down or unreachable: a stopped transport service, a failed node, an expired certificate, or a network path to one site's server.

## Resolution
1. Check the mail server's health in monitoring and test sending from Outlook on the web to tell a server fault from a client fault.
2. If the server is down, raise or link to one P1 major incident and post a status notice.
3. Restart the stopped Exchange transport services, or fail over to the standby node.
4. If only one site (for example Oregon) is affected, check the network route and DNS record for that site's mail server.
5. Link every user report to the major incident as a child instead of working them separately.

## Notes
This keeps coming back (INC0000032 says "down again"). After restoring service, open a problem record to find the root cause.
