# KB0010013: Internal websites, wiki and IT tools

**Category:** Web  
**Assignment group:** Software  

## Tickets

- INC0009001: Unable to post content on a Wiki page (New)
- INC0000024: Issue with a web page on wiki (Closed)
- INC0000040: JavaScript error on hiring page of corporate website (On Hold)
- INC0000029: I can't get my weather report (In Progress)
- INC0009004: Defect tracking tool is down. (Closed)
- INC0000031: Need help with Remedy. Can we configure UI? (In Progress)

## Symptoms
An internal site, wiki page, corporate web page or IT tool shows errors, won't load, or can't be changed.

## Cause
A recent site change, a page script error, missing edit permission, or the tool's server being down.

## Resolution
1. Ask for the page link, a screenshot and the browser.
2. Try it in a private window to rule out the browser cache and extensions.
3. For a script error, open the browser console (F12), note the error and pass it to the site owner.
4. For wiki editing, check the user's edit permission on that space.
5. If a tool is down for everyone, check its server and raise an outage.

## Notes
Configuration requests (such as changing a tool's UI) are changes, not incidents.
