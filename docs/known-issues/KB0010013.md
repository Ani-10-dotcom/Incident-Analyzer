# KB0010013: Nightly database backup job failed

**Category:** Database  
**Assignment group:** DBA Team  
**Resolved example tickets:** INC0010125, INC0010127, INC0010132, INC0010133, INC0010142

## Symptoms
The nightly backup job ends with a failed status.

## Cause
The backup volume is full, or a long-running query held a lock past the backup window.

## Resolution
1. Check free space on the backup volume; remove backups older than the retention period.
2. Check the job log for lock timeout errors and find the blocking session.
3. Rerun the backup manually and confirm it completes.
4. If it fails two nights in a row, raise the priority to P2.
