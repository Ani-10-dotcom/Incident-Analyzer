# KB0010008: Laptop slow after Windows update

**Category:** Hardware  
**Assignment group:** Desktop Support  
**Resolved example tickets:** none yet

## Symptoms
Laptop is very slow, fan running, for hours after a Windows update.

## Cause
Post-update tasks (search indexing, .NET optimization, antivirus full scan) run together, often on laptops with under 8 GB RAM.

## Resolution
1. Restart the laptop twice to let pending update steps finish.
2. Open Task Manager and check what is using CPU and disk. Leave indexing and scans to finish if they are running.
3. Run `sfc /scannow` as admin if slowness lasts more than a day.
4. If RAM is under 8 GB, raise a hardware upgrade request.
