# KB0010008: Wi-Fi, network and VPN connectivity

**Category:** Network  
**Assignment group:** Network  

## Tickets

- INC0000003: Wireless access is down in my area (In Progress)
- INC0000030: Lost connection to the wireless network (Closed)
- INC0000057: Performance problems with wifi (New)
- INC0000036: Issue with networking (Closed)
- INC0000015: I can't launch my VPN client since the last software update (In Progress)

## Symptoms
User loses Wi-Fi, has slow wireless, has a general network problem, or the VPN client won't start.

## Cause
A failed or overloaded wireless access point, an expired Wi-Fi certificate, a bad adapter driver, or a software update that broke the VPN client.

## Resolution
1. Ask where the user is. If several users in one area have no Wi-Fi, check that area's access point and controller.
2. For one user, forget and rejoin the network, and update the wireless adapter driver.
3. Test speed on wired and wireless to tell a Wi-Fi problem from a wider network problem.
4. If the VPN client won't launch after an update, reinstall the approved VPN version from Software Center, or roll back the update.
5. Confirm the user can reach an internal site.

## Notes
Escalate to Network with the location, access point name and time if a whole area is affected.
