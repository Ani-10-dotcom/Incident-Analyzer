# KB0010016: ATF test records

**Category:** Test  
**Assignment group:** Service Desk  

## Tickets

- INC0008112: Assessment :  ATF Assessor (New)
- INC0008111: ATF : Test1 (New)
- INC0008001: ATF:TEST2 (New)

## Symptoms
Tickets named "ATF" or "Test" that no user reported.

## Cause
Created by the ServiceNow Automated Test Framework (ATF) or by someone testing the instance.

## Resolution
1. Confirm with the platform team that the test run has finished.
2. Close the records as "Test" or delete them on a test instance.
3. Have ATF clean up the records it creates so they don't appear in reports.

## Notes
These tickets distort counts. Leave them out of reporting.
