# KB0010011: Software install, patch and virtual machine problems

**Category:** Software  
**Assignment group:** Software  

## Tickets

- INC0000027: Please remove the latest hotfix from my PC (In Progress)
- INC0000010: Need Oracle 10GR2 installed (Closed)
- INC0000019: Can't launch 64-bit Windows 7 virtual machine (In Progress)

## Symptoms
User needs software installed or a patch removed, or a virtual machine won't start.

## Cause
A hotfix that broke something, software that isn't in the self-service catalog, or virtualization turned off in BIOS or not supported by the host.

## Resolution
1. Hotfix: confirm which update caused the problem, uninstall it from Settings > Windows Update > Update history, and pause it until it's fixed.
2. Install requests: check the license and approval, then install from Software Center or package it.
3. 64-bit VM won't start: turn on Intel VT-x or AMD-V in BIOS, and turn off Hyper-V if the VM software needs it.
4. Confirm the user's software now works.

## Notes
Report a bad hotfix to the patching team so it can be stopped for everyone.
