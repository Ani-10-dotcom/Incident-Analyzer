# KB0010010: Shared drive access denied

**Category:** Access  
**Assignment group:** Identity & Access  
**Resolved example tickets:** INC0010053, INC0010095, INC0010108, INC0010139, INC0010141

## Symptoms
User gets 'Access denied' on a shared folder or report they need.

## Cause
The user isn't in the security group that grants access, or was added recently and hasn't signed out since.

## Resolution
1. Check which group grants access to the folder or report.
2. If the user should have access, get approval from the data owner, then add them to the group.
3. Ask the user to sign out and back in (or lock and unlock) so the new group membership applies.

## Notes
Never grant access to individuals directly; always through a group.
