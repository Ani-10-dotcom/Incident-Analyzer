# KB0010002: Email slow, not loading or can't connect

**Category:** Email  
**Assignment group:** Software  

## Tickets

- INC0000060: Unable to connect to email (Closed)
- INC0000047: Issue with email (In Progress)
- INC0000001: Can't read email (Closed)
- INC0000058: Performance problems with email (New)
- INC0000013: EMAIL is slow when an attachment is involved (Closed)

## Symptoms
One user's Outlook can't connect, won't open messages, or is very slow, often when sending or opening attachments. Other users are fine.

## Cause
Usually a local problem: a corrupted Outlook cache (OST) or profile, a mailbox near its size limit, a slow network link, or an add-in scanning attachments.

## Resolution
1. Check Outlook on the web. If mail works there, the server is fine and the problem is the client.
2. Check mailbox size against the quota and archive or clean up if it is near the limit.
3. Close Outlook, rename the .ost file in `%LOCALAPPDATA%\Microsoft\Outlook`, and reopen Outlook to rebuild the cache.
4. Start Outlook with `outlook.exe /safe`. If it is fast, disable add-ins one at a time to find the slow one.
5. If it still fails, create a new Outlook profile from Control Panel > Mail.

## Notes
If several users report the same thing at once, treat it as a server outage (KB0010001).
