# KB0010002: Outlook not syncing email

**Category:** Email  
**Assignment group:** Messaging  
**Resolved example tickets:** INC0010069, INC0010111, INC0010128, INC0010130, INC0010147

## Symptoms
New mail stops arriving in Outlook desktop while Outlook on the web shows it. Status bar may say 'Disconnected' or 'Updating this folder'.

## Cause
A corrupted local OST cache file, or Cached Exchange Mode stuck after a password change.

## Resolution
1. Check Outlook on the web. If mail is there, the mailbox is fine and the problem is the local client.
2. Close Outlook, rename the .ost file in %LOCALAPPDATA%\Microsoft\Outlook to .ost.old.
3. Reopen Outlook and let it rebuild the cache (can take 10-30 minutes for large mailboxes).
4. If prompted, re-enter the password; clear old entries in Credential Manager first.

## Notes
If web mail is also missing messages, treat as a mail-flow incident and check the email server status (see KB0010003).
