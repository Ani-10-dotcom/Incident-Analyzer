# KB0010003: Password reset and sign-in problems

**Category:** Access  
**Assignment group:** Service Desk  

## Tickets

- INC0000035: Reset my password (Closed)
- INC0000009: Reset my password (Closed)
- INC0000004: Forgot email password (Closed)
- INC0009003: Cannot sign into the company portal app (Closed)

## Symptoms
User forgot their password, is locked out, or can't sign in to an app or the company portal.

## Cause
Forgotten or expired password, an account locked after too many attempts, or old saved credentials after a password change.

## Resolution
1. Verify the user's identity using the standard check (employee ID and manager, or a call-back).
2. Unlock the account and set a temporary password that must be changed at next sign-in, or point the user to self-service password reset.
3. Ask the user to clear saved passwords for the app (Windows Credential Manager, browser, phone mail app).
4. Have the user sign in once while you're on the call to confirm it works.

## Notes
Encourage self-service reset to cut these tickets. Repeated lockouts can mean an old device is still using the old password.
