# KB0010003: Email server outage

**Category:** Email  
**Assignment group:** Messaging  
**Resolved example tickets:** INC0010113, INC0010114, INC0010115, INC0010120, INC0010126

## Symptoms
Many users at once cannot send or receive email, in both Outlook and on the web.

## Cause
Mail service outage, usually a failed transport node or an expired TLS certificate on the mail gateway.

## Resolution
1. Raise a P1 major incident and post a status-page notice.
2. Check the mail gateway health dashboard and certificate expiry date.
3. Fail over to the secondary transport node if the primary is down.
4. Link all user reports to the major incident as child tickets instead of working them separately.

## Notes
Messaging on-call owns this. Every duplicate report should reference the parent P1.
