# KB0010004: Business application outage (SAP, payroll)

**Category:** Application  
**Assignment group:** Software  

## Tickets

- INC0000055: SAP Sales app is not accessible (In Progress)
- INC0000054: SAP Materials Management is slow or there is an outage (On Hold)
- INC0000053: The SAP HR application is not accessible (In Progress)
- INC0000052: SAP Financial Accounting application appears to be down (In Progress)
- INC0000051: Manager can't access SAP Controlling application (In Progress)
- INC0000044: Can't log into SAP from my laptop today (In Progress)
- INC0007001: Employee payroll application server is down. (New)

## Symptoms
Users can't reach an SAP module (Sales, Materials Management, HR, Financial Accounting, Controlling) or the payroll application, or it is very slow. Often several modules at once.

## Cause
A shared back end is down or overloaded: the SAP application or database server, the message server or login service, or the payroll app server. Several SAP modules failing together points to a shared component.

## Resolution
1. Check whether one module or several are affected. Several at once means a shared back-end problem, so raise one P1 major incident.
2. Check the application and database servers in monitoring (CPU, memory, disk, services).
3. For SAP, check the message server and work processes, and restart failed instances in the documented order.
4. For payroll, restart the application service, then the integration service, and tell HR leadership if pay deadlines are at risk.
5. If only one user can't log in (for example from their laptop), check their SAP GUI connection settings and account lock instead.
