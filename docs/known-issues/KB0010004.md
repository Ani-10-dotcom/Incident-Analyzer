# KB0010004: SAP portal login fails (error 403)

**Category:** Application  
**Assignment group:** SAP Support  
**Resolved example tickets:** INC0010104

## Symptoms
User gets error 403 or 'not authorized' when signing in to the SAP portal.

## Cause
The user's SAP role assignment expired, or the SSO token is cached from an old session.

## Resolution
1. Ask the user to sign in from a private browser window. If that works, clear browser cookies for the portal domain.
2. If it still fails, check the user in SU01 for locked status and role validity dates.
3. Extend or reassign the expired role (needs manager approval for new roles).
4. Ask the user to sign out and back in after 10 minutes for the role to sync.

## Notes
Locked accounts after 5 failed attempts are unlocked by the service desk; role changes go to SAP Support.
