# KB0010007: Workday password reset and timesheet page

**Category:** Application  
**Assignment group:** HR Systems  
**Resolved example tickets:** INC0010078, INC0010096, INC0010117, INC0010129, INC0010152

## Symptoms
User cannot sign in to Workday, or the timesheet page spins without loading.

## Cause
Workday uses company SSO, so password problems are usually the main company password. Timesheet hangs are a browser cache issue after a Workday release.

## Resolution
1. For sign-in: reset the company password through the self-service reset portal, then sign in to Workday through SSO.
2. For the timesheet page: clear cache and cookies for the Workday domain, or try a private window.
3. If only one user is affected after both steps, collect a screenshot and the time it happened, and route to HR Systems.
