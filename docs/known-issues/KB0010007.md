# KB0010007: Server health: storage full, backup failed, CPU, data center

**Category:** Infrastructure  
**Assignment group:** Hardware  

## Tickets

- INC0000033: File Server is 80% full - Needs upgrade (Closed)
- INC0000034: Does not look like a backup occurred last night (Closed)
- INC0000005: CPU load high for over 10 minutes (Closed)
- INC0000016: Rain is leaking on main DNS Server (In Progress)

## Symptoms
A monitoring alert or engineer reports a server problem: disk filling up, a missed backup, sustained high CPU, or physical risk to equipment.

## Cause
Capacity not planned for growth, a failed or skipped backup job, a runaway process, or a facilities problem in the server room.

## Resolution
1. Physical risk (water, heat, power) comes first: protect or power down the equipment safely and call facilities.
2. Disk full: find large or old files, clear temp and logs, and raise a change to add storage before it reaches 90%.
3. Missed backup: check the backup console for the job's error, rerun it, and confirm it completes.
4. High CPU: find the process in Task Manager or `top`, restart it if it's hung, and check for a recent change.
5. Record the root cause and add a monitoring threshold so it's caught earlier.

## Notes
INC0000016 (water on the DNS server) threatens a core service. Treat it as P1 and have a DNS failover plan ready.
