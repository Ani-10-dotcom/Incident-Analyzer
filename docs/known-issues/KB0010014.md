# KB0010014: Phones and mobile devices

**Category:** Hardware  
**Assignment group:** Hardware  

## Tickets

- INC0000041: My desk phone does not work (In Progress)
- INC0000020: I need a replacement iPhone, please (In Progress)
- INC0000011: Need new Blackberry set up (Closed)

## Symptoms
Desk phone is dead or has no dial tone, or a user needs a mobile phone replaced or set up.

## Cause
Loose cable or failed PoE port, a phone not registered with the phone system, or a damaged or new mobile device.

## Resolution
1. Desk phone: check the network cable and power, try another port, and check the phone's registration.
2. Replacement phone: confirm eligibility, order from the mobile catalog, and transfer the number.
3. New mobile setup: enroll it in device management, then set up email and apps.

## Notes
Device orders are requests. Only a broken device is an incident.
