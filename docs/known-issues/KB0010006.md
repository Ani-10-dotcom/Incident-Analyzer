# KB0010006: Payroll application down

**Category:** Application  
**Assignment group:** HR Systems  
**Resolved example tickets:** INC0010077, INC0010112

## Symptoms
Payroll application shows a server error or will not load for everyone.

## Cause
Usually the application server hit its database connection limit during a payroll run, or a scheduled patch did not finish.

## Resolution
1. Raise a P1 and inform HR leadership; payroll deadlines may be affected.
2. Check the app server and database connection pool in monitoring.
3. Restart the application service in the documented order (app, then integration service).
4. Confirm with one HR user that they can sign in, then link duplicate reports to the P1.

## Notes
HR Systems on-call owns this.
