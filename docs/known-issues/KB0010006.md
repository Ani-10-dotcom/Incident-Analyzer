# KB0010006: File is read-only or locked, and folder how-to

**Category:** Storage  
**Assignment group:** Service Desk  

## Tickets

- INC0000018: Sales forecast spreadsheet is READ ONLY (In Progress)
- INC0000038: my PDF docs are all locked from editing (Closed)
- INC0000017: How do I create a sub-folder (On Hold)

## Symptoms
User can open a file but can't edit or save it, or needs help with basic file tasks like creating a folder.

## Cause
Someone else has the file open, a stale lock file was left behind, the file is marked read-only or protected, or the user only has read permission on the folder.

## Resolution
1. Check whether someone else has the file open (Excel shows who). Ask them to close it.
2. Look for a hidden lock file (`~$filename`) in the same folder and delete it if nobody has the file open.
3. Check file properties: untick Read-only, and for PDFs check whether the document has an editing password.
4. Check folder permissions. If the user needs write access, get the data owner's approval.
5. For how-to questions, walk the user through it and send the self-help article.

## Notes
How-to questions are not incidents. Close them as requests with a link to the article.
