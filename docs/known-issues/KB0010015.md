# KB0010015: Service requests logged as incidents

**Category:** Request  
**Assignment group:** Service Desk  

## Tickets

- INC0000037: Request for a new service (In Progress)
- INC0000021: New employee hire (Closed)

## Symptoms
The ticket asks for something new (a service, onboarding a new hire) rather than reporting something broken.

## Cause
The user picked the wrong form, or the request catalog item isn't easy to find.

## Resolution
1. Thank the user and open the right request (for example New Hire Onboarding) with their details.
2. Link the request to the incident and close the incident as "Logged as request".
3. Send the user the link to the catalog item for next time.

## Notes
Many of these mean the catalog needs a clearer entry point.
